- `AstralBlizzardUI.lua` rewritten: role icons were faded with every `lfgframe` texture and the zip's role coords/button names didn't match 3.3.5 (now `LFDQueueFrameRoleButton*` etc. with `GetTexCoordsForRole`); `"stone"` hid `INV_Stone_*` icons; the `ui%-panel%-background` pattern with plain find never matched; `StyleButton` ran `UI.CosmicButton` on every Blizzard button with text (stripped quest reward / gossip icons, now only `UI.SkinTree` panel buttons); `SetWhiteText` forced all text white (now only dark parchment text); auto-loot hid `LootFrame` directly (now `CloseLoot`); 0.05s watcher re-selected quests on every tick (removed, events only; watcher 0.2s); flat black + 1px outline + Astral close buttons that keep Blizzard's OnClick
- `AstralDPS.lua`: `GetRaidRosterInfo` class is the 6th return (10th is the role); recent lists pruned on insert (`PushRecent`); stale recent lists/timers cleared on ADDON_LOADED; globals renamed `ProjectAstralDPS` / `ProjectAstralDPSDB` (TOC too) because the enabled standalone `DPS` addon uses `DPS` / `DPSDB` and both wrote into one table; `/dps` says when the meter is off; load message no longer mentions the hidden minimap button

- `PrestigeStore.lua`: `RebuildTabs` created new buttons on every refresh (pooled); `ShowCategory` / filter buttons reset the offset but not the scroll bar, and used `Disable()` without the disabled look
- `AstralChat.lua`: unguarded `SetWordWrap`
- New `AG.LoadoutGemStatus(text)` (AstralGems) and gem availability in `GemBuilds.lua` (row, load status/chat, tooltip); rows refresh on `GemStash.OnStockChanged`

### Fixed
- Full-addon scan (Lua 5.1 parser run over all 99 .lua files, TOC/XML include check, FrameXML.log):
  - No syntax or load-limit (200 locals / 60 upvalues) errors
  - `Leaderboard.lua`: `local listFrame` was declared below `SendServer`, so `SendServer` read a nil global and never showed the loading overlay; now declared above it
  - `AstralDPS.lua` `UpdateGroupMembers`: `_` was assigned as a global (`_, class = UnitClass(...)`); now local
  - FrameXML.log "Error loading" for AstralBlizzardUI/AstralDPS/AstralGemTracker: new TOC files need a full client restart, not /reload
  - Left as is: `AIO_Client/queue.lua` `Queue.clear` uses a nil `self` and undefined `idx` (nothing calls it); `Mythic.lua`, `MythicPlus.lua`, `InspectGems.lua` are in no TOC (Mythic.lua would overwrite Blizzard's `UIDropDownMenu_AddButton` if ever loaded); Transmogrification sets lower-case globals (`transmogrificationEquipmentSlotMap`, `characterTransmogTab`, ...)
- Mount Journal: the preview `PlayerModel` isn't clipped to its frame, so in a windowed hub the mount spilled over the list. The model now only shows while `PA.mainFrame._fullscreen` (checked every frame in the panel's OnUpdate, so it follows the fullscreen button at once); otherwise the mount icon and a "go full screen" note
- Hub window: dragging it stuttered the game (moving the real frame re-lays out every region each frame; the skill tree canvas has thousands)
  - Tried first: drag a ghost outline and move the hub on drop. Players saw the contents (Token Store items, Mount Journal) left behind, so it was replaced
  - Now the hub moves live with `StartMoving`, and `AT_ScrollFrame` is hidden for the drag when it's visible
  - On drop: `SaveCenter`, then Settings' OnDragStop hook saves the position
  - A watcher ends the drag once the left mouse button is up
- Astral Chat:
  - The dock's first tab is re-anchored so its pill starts flush with the chat background's left edge (checked in the 0.1s watcher)
  - Edit boxes are anchored to the chat background (TOPLEFT/TOPRIGHT → BOTTOMLEFT/BOTTOMRIGHT ∓3, +1) so the box spans the window end to end
- Token Store: buying an item no longer resets the store to the first category — the post-purchase refresh restores the category, filter, scroll position and selected item, so the same item can be bought again straight away
- `Theme.lua`: stack overflow (`AT_Canvas:GetRegions()`) when opening the Skills tab — the skinner now skips the skill-tree canvas and any frame with more than 400 regions/children
- `AIO_Client/AIO.lua`: "an event is already registered for the name: Astralgem" when the server-sent AstralGemsEditor addon loads — a second handler for the same AIO name is now chained instead of rejected (GemFusion.lua already uses that name)

### Changed — Hub UI revamp (grouped tabs)
- `/astral` hub replaces the per-module sidebar with tabs, each a scrolling page of cards (single-card tabs are centred):
  - **Skills** — Astral Skill Tree with a built-in Class Talents column (toolbar "Talents" button shows/hides it)
  - **Stats** — new `AstralStats.lua`: every bonus gained from unlocked Astral Tree nodes and Paragon points, in Offensive / Defensive / Quality of Life columns with Paragon share shown, plus nodes / Paragon / unspent-points chips. Uses the same totals as the tree's Total Bonuses panel (`AT.NodeTotals`, `AT.ParagonTotals`, `AT.OnStatsChanged`)
  - **Gems** — Astral Gems, Gem Fusion and Gem Stash side by side in one row; the tab's `fit` flag scales that row down to fit the window's width and height so it never scrolls (card titles stay full size). Gem Fusion's stash button jumps here; old `stash` tab id maps to it
- Hub window border removed: plain edge-to-edge background
- Icons instead of coloured dots: `UI.MakeChip` takes `opts.icon` (icon on a dark square; chip keeps its tinted border, stores `_minW`/`_pad`), shared `UI.Icon` currency table (Core.lua). Used by the hub header chips (tokens, orbs, prestiges, lockouts), Stats tab chips, and Token Tracker rows
- Prestige (`PA_PrestigeFrame`) and Astral Challenges (`PA_ChallengesFrame`) windows: grey `UI.MakePanel` border removed via new `UI.FlatBackdrop` (Theme.lua)
  - **Update Log** — new `UpdateLog.lua`: player-facing "what's new" list (New / Improved / Fixed), newest first; green dot on the tab and a chat notice after login while there's an update the player hasn't opened (`lastSeenUpdate` setting). Add an entry to its `UPDATES` table for every player-visible change
  - **Gem Builds** — new `GemBuilds.lua`: save the gems you have socketed under a name, import shared loadouts as builds, hover a build to preview every slot, Load (one click, same rules as gem import), Export, Delete (click twice). Stored account-wide in the new `ProjectAstralGemBuilds` saved variable so every character can use them
  - **Store** — Token Store, Collections (sub-tabs Store Mounts / Heirlooms / Rewards; briefly moved to the Mounts tab, moved back)
  - **Mounts** — Mount Journal only (store mounts live on the Store tab); clicking its model (without dragging) opens the full-screen `MountViewer`. New `MountJournal.lua` (Mount Journal: the character's known mounts from `GetCompanionInfo("MOUNT")` plus spellbook-only custom mounts from MountSafe's `PA.CustomMountIds`; search, rotating `PlayerModel:SetCreature` preview, Summon/Dismount via `CallCompanion`/`Dismount` (spell-only mounts use `.mount <id>`), Random mount, drag to action bar via `PickupCompanion`, Shift-click link, `/mounts` / `/mountjournal`) beside Collections (sub-tab renamed Store Mounts / Heirlooms / Rewards), moved out of the Store tab; old `collections` tab id maps to it
- Collections: Store Mounts / Heirlooms match the store category case-insensitively and by substring (`CategoryKind`: mount/mounts/Reittier, heirloom/Erbstück); it used an exact `== "Mount"` / `"Heirloom"` match
- Token Store (`PS.ApplyStore`): entries whose category isn't in `payload.categories` get their category added instead of being dropped; skipped entries (no id/item) are counted
- New `MountViewer.lua`: full-screen mount viewer (black screen, `PlayerModel` only, FULLSCREEN_DIALOG, Esc/click/right-click closes, drag turns, wheel zooms via `SetModelScale`, controls hint fades after 2.5s)
  - Opened from a **View** button or Ctrl-click on mount entries in Collections (Store Mounts) and in Token Store mount categories
  - Model source: a creature/display id in the server entry or item meta (`creature`, `creatureId`, `displayId`, ... kept via new `raw` fields), else the matching known mount (`GetCompanionInfo`, by spell or normalised name)
  - Otherwise it shows a UIErrors message and doesn't open
- `/storedebug`: also prints the fields of the first Store Mount / Token Store mount entry
- `/storedebug`: prints the Token Store categories/item counts, skipped entries (with a sample), and Collections' loading state and categories
- Collections: cards no longer live in a `UIPanelScrollFrameTemplate` scroll child
  - That nested ScrollFrame inside the hub's scrolling page made the items (e.g. Heirlooms → Misc bags) stay behind, drawn under the window, while the hub was dragged
  - Cards now sit on a plain `grid` frame, the mouse wheel pages through rows (`gridOffset`), and a thin thumb shows position
  - Same nesting remains in UpdateLog.lua and GemFusion.lua (line ~1209)
- Collections: 8s load timeout. The overlay used to stay up forever and `receiving` stuck when the server never replied, so reopening never re-requested. Also shows empty/failed text per sub-tab
  - **Raid** — Raid Lockouts
  - **Leaderboards** — Leaderboard
  - **Reagent Bank** — Reagent Bank
  - **Settings** — Settings (any future module without a tab lands here)
- Tab bar drops its icons when the window is too narrow for all tabs
- Hub footer (version/mouse-wheel hint and "Back to top" button) removed; the page uses the space
- Talent key (N / whatever is bound to Toggle Talent Pane) opens the hub's Skills tab (and shows the talents column) instead of Blizzard's talent window; pressing it again closes the hub. Uses a session-only override binding, so saved keybinds are untouched. Toggle in Settings → "Talent key (N) opens this hub"
- Hub window is resizable (bottom-right grip: drag = resize, Shift+drag = scale 0.6–1.4) and has a fullscreen toggle in the header; size, scale and fullscreen are saved. The skill tree stretches to fill the extra width/height
- New `Theme.lua` (`UI.SkinTree`): restyles Blizzard template widgets inside Astral frames — scroll bars, dropdowns (and their popup lists), sliders, check boxes, input boxes, panel buttons, gold list highlights, default gold text, navy backdrops — to the Astral look. Applied to every hub card, the gem picker, and the Builds window. Also `UI.MakeTextDialog` (themed export/import dialog)
- Docked class talents are transparent: all Blizzard art (frame border, portrait, class background, scroll/points-bar art, tree-tab and spec-tab backings, title) is faded out, leaving only the talents, branch arrows, text, scroll bar, spec-switch tabs and buttons. Tree tabs become text with an underline on the selected tree; Learn/Reset/Activate get an Astral box. Re-applied on tree/pet/glyph switches and fully restored on undock (N-key window unchanged). The column box is replaced by a hairline divider
- Astral Gems: **Export / Import loadout** (`AGEMS:1:` text). Paste and click Import (one click, no separate check step) to socket gems you own into empty, active sockets one at a time — what was socketed/skipped is printed to chat. It always first unsockets gems in the way — a different gem in a build socket, or the same gem family in another socket — only when a stash gem can replace them, refreshes sockets + stash, re-plans, then sockets the new gems. If a gem isn't in your stash, the highest lower tier of the same gem (same family) you own is used instead — never a higher tier than the loadout lists
- Settings: "Reset window position" also resets size and fullscreen; scale slider range 0.6–1.4
- Settings tab uses the full card width: three columns (General + Behavior · Gain Popup · Popup Colours + World Chat + Reset) when the card is 900px+ wide, stacked when narrower. `PANEL_SIZE[...].h` in MainMenu may now be a function of panel width
- Token Tracker **options window** (Astral-themed, live preview), adapted from Seville's standalone TokenTracker addon: style (Detailed / Compact), show Orbs, lock, font (Friz Quadrata, Arial Narrow, Morpheus, Skurri, Comic Sans), size 10–24, text colour, outline (normal / thick / none), shadow colour, background opacity (0 = text only; hides outline + accent), reset appearance, reset size & position. Open via right-click → Options…, Settings → "Tracker options…", `/tokentracker options`, or `/ttc` (only when the standalone TokenTracker addon isn't loaded; otherwise a one-time chat note suggests disabling it)
- New `AstralChat.lua`: **Astral chat style** for Blizzard's chat windows (on by default, `chat.skin`; off needs /reload):
  - Blizzard chat art cleared (`CHAT_FRAME_TEXTURES`, tab and edit-box textures) and replaced by a black background (`chat.bgAlpha`, default 0.9; saves from the first version move to 0.9 once via `chat.blackBg`) with a 1px outline and blue top line
  - Tabs: muted text, white (or whisper-coloured) text with an underline when selected, hover tint, new-message flash as a soft tint
  - Tab icons + black backing with 1px outline:
    - Icon picked from the tab name (`TAB_ICONS`: combat, general, party, raid, guild, trade, loot, whisper, world, pvp…); whisper windows get a letter, anything else a note
    - Icon is desaturated/dimmed unless the tab is selected or hovered
    - Tabs are widened by 18px (re-applied after `PanelTemplates_TabResize`) with the name nudged right; the dock is re-laid out via `FCF_DockUpdate`
  - Message box: flat box with a left bar in the current chat type's colour (`ChatEdit_UpdateHeader` hook)
  - Resize grip (bottom-right, shows on hover; docked tabs resize the dock) that works on locked windows and saves via `FCF_SavePositionAndDimensions`
  - Mouse wheel (Shift = page, Ctrl = top/bottom) and a jump-to-newest arrow while scrolled up
  - Blizzard button frames, resize button, `ChatFrameMenuButton` and `FriendsMicroButton` hidden; replaced by Astral friends (online count) and emote-menu buttons at the right of the tab row
  - Temporary (whisper) windows skinned via an `FCF_OpenTemporaryWindow` hook; they get a hover **x** close button, and middle-click closes them
- **Whisper tabs**: `whisperMode` CVar set to `popout_and_inline` on first login (`chat.whisperTabs` / `chat.whisperInline`, `chat.whisperModeSet`). After that the CVar is the source of truth, so Interface Options > Social changes stick. As a backup, a whisper sent or received without a tab opens one a frame later and is replayed into it
- Settings: new **CHAT** section in column 1 (style, whisper tabs, also show in main chat, background opacity); stacked layout heights updated (Settings card 1448px when narrow)
- New `TokenTracker.lua`: on-screen **Token Tracker** (shown by default, independent of the hub). Tokens (optionally Orbs), "+N this session · N/hr", tooltip with earned/spent/orbs/session time. Drag to move, corner grip to scale (0.6–2.0), right-click themed menu (lock, show orbs, reset session, reset size/position, hide), `/tokentracker`. Saved in `tokenTracker` settings; Settings tab column 3 has Show / Lock check boxes
- Reagent Bank: **Auto-deposit reagents** checkbox (on by default, `reagentAutoDeposit`). 2s after bags change it sends `DepositAll` when the bank is unlocked and Trade Goods (localized auction class 6) are in the bags; paused in combat, while casting, and while TradeSkill/Bank/Mail/Trade/Auction/Merchant/GuildBank frames are open (so crafting's bank pulls aren't pushed back). Skips repeat attempts on unchanged leftovers; auto runs are silent when nothing moved and print a short "Auto-deposited N items" otherwise
- Astral Table restyled to the hub look: flat dark window + 1px outline with a purple (Gems-tab) top glow instead of Blizzard dialog art, white outlined titles, outlined slots with purple hover, muted/white text, same chrome on the tier-table and filter pop-outs, `UI.SkinTree` for its check boxes
- Astral Table (`AstralDisenchant.lua`): **Auto-deposit gems into Gem Stash** checkbox (on by default, `disenchantAutoDeposit`). When a batch yields a gem or scroll, 1s after Batch_end it sends `.astralstash depositall` and refreshes the stash (which also lets Auto Fuse run if enabled). Window 26px taller to fit it. Mailed rewards aren't deposited
- Gem Fusion: **Auto Fuse** toggle + "Fuse up to" tier (T2–T8). Fuses 3× same gem → next tier from the Gem Stash, lowest tier first so results cascade, one request at a time; skips tiers not unlocked, pauses in combat or when gold runs short (resumes when gold/combat changes), runs on stash changes and gem drops even with the hub closed, one summary popup per run. Saved as `autoFuse` / `autoFuseMaxTier`
- Gem picker (socketing a gem) is larger (560×620), has a search box (name or family, cleared per socket) and closes with Esc
- New look: icon tab bar with a sliding underline, per-tab accent colour that fades across the header band, tab glow and card headers, pulsing logo, coloured dot currency chips, page fade on tab switch
- New `ClassTalents.lua`: Blizzard's talent frame docks into a column inside the Astral Tree card while it's on screen and is handed back untouched otherwise (N key still works)
- Gem Stash is embedded in the Gems tab; `GS.Toggle()` / Gem Fusion's stash button open it there
- Cards build and request server data only when on screen, and go idle when off screen
- Skill tree "Bonuses" panel now docks inside the tree card instead of floating beside the window
- Settings: inner scroll removed, slider mouse-wheel removed, "Refresh when switching tabs" removed, "Remember last open tab" → "Reopen the tab I was on", "Default tab" → "Start on tab"
- `mf:SwitchTab(id)` kept for module toggles / slash commands — accepts a tab id or a module name

### Added
- Live **Prestige Tokens** and **Prestige Level** display in the info panel (bottom-left)
- `AT.costs` table — token cost per tier received from the server via new `AT|COST` messages
- `AT.prestigeTokens` and `AT.prestigeLevel` data fields, updated whenever the server sends `AT|PRESTIGE_TOKENS` / `AT|PRESTIGE_LEVEL`

- Unlock button label now shows cost in brackets (e.g. `Unlock  [3 Tokens]`)

### Changed
- `AT|NODE` parsing now stores the `tier` field (was received but silently discarded)
- `AT|COST` message format updated to `AT|COST|<tier>|<count>` (server dropped the `item_id` field)
- `UNLOCK_FAIL` handler checks the reason code before printing the error message
